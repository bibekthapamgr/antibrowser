## Implementation steps
| Step | Status |
|---|---|
| Restrictive CSP; external links open in the system browser | Done. `script-src 'self'`, no remote origins; navigation locked to the bundle, new windows denied; only `https://github.com/…` help links open |
| Typed commands incl. list/create/launch/stop profile, runtime status, download folder | Done: 19 commands, TypeBox contract (`packages/contracts/src/ipc.ts`), generated `docs/ipc-schema.json`; every command checks the caller window and validates input |
| Minimal capabilities | Done: one capability, `main` window only, one permission per command plus event listen; a test fails if contract, permissions, capability and handler list drift |
| SQLite migrations with FK and WAL; failed migration keeps previous DB + recovery action | Done: v2 migration in one transaction, backup before upgrade, recovery screen (retry / restore / export diagnostics) |
| OS app-data dirs; generated ids; reject traversal and symlinks | Done (local app data, see ADR-0009 item 2) |
| Deep links | Done: `projectbrowser://auth/callback` only, bound to one-time state |
| Tray / quit with running count; cancel or graceful close-all | Done |
| Signed internal installers with checksums and provenance | **Partly**: workflow builds NSIS/MSI/DMG/.app with `SHA256SUMS`, `provenance.json` and an attestation attempt; signing activates when the owner adds certificates (see below) |
| Local records: devices, settings allowlist, runtime_installations | Done (+ workspaces, timings, auth_transactions) |
| operation_id + events for long tasks | Done (`operation` event, Downloads screen) |
| Debounced search; virtualized tables | Done (150 ms debounce; 10,000 rows render < 100 DOM rows) |
| Repository interfaces for a later cloud adapter | Done (`apps/desktop/src/backend/types.ts`) |

## Failure and security behaviour
| Case | Behaviour | Test |
|---|---|---|
| Low disk | install refused with `INSUFFICIENT_DISK_SPACE` (256 MiB margin) | `crates/update` |
| Interrupted install | journal detected at start, shown on Downloads, discard action | `crates/update`, `ipc.rs` |
| Failed digest | archive moved to quarantine, never extracted | `crates/update` |
| Missing keychain | secret persistence disabled, shown in Settings | `secrets.rs` |
| Crash telemetry | opt-in (default off), scrubbed, local only | `recovery.rs` |

## Acceptance
| Criterion | Status |
|---|---|
| Install / launch / uninstall with a clear data-removal choice | Workflow smoke-tests per-user NSIS install + silent uninstall on Windows and mounts the DMG on macOS. Data removal: NSIS checkbox, in-app *Remove all local data* (all OSes). **Manual check on real Windows 11 / macOS still to do** |
| Startup timings recorded separately from Chromium | `manager_startup_ms` and `store_open_ms` stored locally; browser process start is a separate `browser_spawn_ms` series; p50/p95 shown in Diagnostics (`ipc.rs` checks they never mix). **Reference-device numbers not yet measured** |
| Invalid IPC path, oversized request, disallowed URL rejected | `ipc.rs` |
| Killing the manager during migration or download leaves a safe state | `ipc.rs` (migration failure → previous DB kept; interrupted install → journal) + storage/update tests |
| Keyboard-only user can create a workspace and reach profile settings | e2e `keyboard-only first run` |
